隱私權政策

更新日期：2026 年 11 月 8 日
本站不需要註冊、不收集你的姓名或聯絡資料。以下說明本站和合作的第三方服務可能使用哪些資料。

本站不收集的資料

瀏覽本站不需要建立帳號，也沒有會員或留言功能，因此本站不會要求你提供姓名、電話、Email 等個人資料。

瀏覽器儲存

首頁的請假計算器會用瀏覽器的本機儲存（localStorage）記住你上次選的請假天數，方便你下次打開時不用重選。這筆資料只存在你自己的瀏覽器裡，不會傳到本站或任何伺服器，你可以隨時從瀏覽器設定中清除。

流量統計

本站使用 Cloudflare Web Analytics 統計整體瀏覽量，例如哪些頁面比較多人看、訪客從哪個網站連過來、使用手機或電腦。這項服務不使用 cookie、不記錄可以辨識個人的資料，也不會跨網站追蹤你；本站只看得到彙整後的統計數字。相關處理方式請參考 Cloudflare 的隱私權政策。

網站主機紀錄

本站架設在 GitHub Pages。和一般網站一樣，主機服務商可能為了安全與維運紀錄訪客的 IP 位址等基本連線資訊，相關處理方式請參考 GitHub 的隱私權聲明。

第三方廣告與 cookie

本站可能使用 Google AdSense 等第三方廣告服務。這些服務商（包括 Google）可能使用 cookie，依據你先前造訪本站或其他網站的紀錄來顯示廣告。

Google 使用廣告 cookie，讓 Google 及其合作夥伴能依據你造訪本站和其他網站的情形放送廣告。你可以前往 Google 廣告設定 關閉個人化廣告，也可以參考 Google 的廣告政策說明。

聯盟連結

本站部分頁面含有 Agoda、Booking.com 等訂房平台的聯盟連結。當你點擊這些連結，訂房平台可能使用 cookie 記錄你是從本站前往，以便計算佣金。這些資料由訂房平台依其隱私權政策處理。詳細說明請見聯盟連結揭露。

外部連結

本站包含連往其他網站的連結。離開本站後，請參考該網站的隱私權政策，本站無法控制外部網站如何處理你的資料。

政策更新

本站可能因為新增服務或法規變更而更新本政策，更新後會修改本頁上方的更新日期。
